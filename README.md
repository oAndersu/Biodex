# 🌿 BioDex

BioDex é uma aplicação web inspirada em uma **Pokédex**, mas voltada para a biodiversidade. Através da câmera do dispositivo, o usuário pode identificar animais e plantas e visualizar informações detalhadas sobre cada espécie.

## ✨ Funcionalidades

- 📷 Identificação de animais e plantas pela câmera.
- 🔍 Exibição de informações da espécie.
- 🌎 Dados como classificação, habitat, características e curiosidades.
- 💻 Interface simples e intuitiva.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

## 🔌 APIs

### 🌿 PlantNet API
- Identificação de plantas por meio de imagens.
- Retorna informações como nome científico, família botânica e nível de confiança.

## 🚀 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/oAndersu/Biodex.git
   ```

2. Entre na pasta do projeto:
   ```bash
   cd Biodex
   ```

3. Abra o arquivo `index.html` no navegador ou utilize uma extensão como **Live Server**.

## 🎯 Objetivo

Tornar o aprendizado de biologia mais interativo, permitindo que qualquer pessoa descubra informações sobre animais e plantas de maneira rápida e intuitiva.
